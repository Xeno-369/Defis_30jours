# Challenge 30 Jours de Code

Dépôt dédié à la pratique quotidienne de la programmation.

## Objectifs
* 1 exercice par jour pendant 30 jours.
* 3 langages maîtrisés : Python, C et Pascal.
* Environnement de développement : Vs code sur Kali Linux.

## État d'avancement

* **Semaine 2** : À venir
* **Semaine 3** : À venir
* **Semaine 4** : À venir

* `jour_xx.py`
* `jour_xx.c`
